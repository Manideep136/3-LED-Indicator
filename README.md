# 3-LED-Indicator

A simple 3-LED indicator circuit PCB designed using KiCad. This project demonstrates basic LED interfacing, current-limiting resistors, schematic design, PCB layout, and routing.

Features
3 independent LEDs
Current-limiting resistors for each LED
Simple and beginner-friendly circuit
Compact PCB design
Designed using KiCad
Suitable for basic electronics and embedded-system projects
Can be used as a power/status indicator

Applications

This PCB can be used for:

Power indication
Status indication
Embedded-system projects
Microcontroller projects
Learning PCB design
Testing LED circuits
Basic electronics demonstrations
